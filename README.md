# AC_MS_ITS_GUI

AC_MS_ITS_GUI 是一个用于纤维增强沥青混合料性能预测与模型解释的交互式 Web 应用。应用面向 Marshall Stability (MS) 和 Indirect Tensile Strength (ITS) 两个关键力学性能指标，支持用户输入混合料组成、集料级配、纤维参数和生产条件，并实时获得模型预测结果。

## 主要功能

### 1. 双目标性能预测

应用可同时预测：

- **MS**: Marshall Stability（马歇尔稳定度，kN）
- **ITS**: Indirect Tensile Strength（间接拉伸强度，MPa）

用户输入配合比与材料参数后，应用会输出对应的 MS 和 ITS 预测值，帮助评估不同纤维增强沥青混合料设计方案的力学性能。

### 2. 输入特征支持

应用支持 15 个输入特征，覆盖沥青性质、集料级配、体积参数、纤维参数和生产条件。

**沥青特性：**

- Pe: 针入度
- Du: 延度
- SP: 软化点
- AC: 沥青含量

**集料和体积特性：**

- AV: 空隙率
- VMA: 矿料间隙率
- VFA: 沥青饱和度
- Ag2.36, Ag4.75, Ag9.5: 集料级配

**纤维和生产特性：**

- FT: 纤维类型
- FC: 纤维含量
- FL: 纤维长度
- TS: 纤维抗拉强度
- MT: 混合温度

### 3. SHAP 模型解释

应用提供 SHAP 解释功能，用于分析不同输入特征对 MS 和 ITS 预测结果的贡献。用户可以查看关键特征如何推动预测值升高或降低，从而提升模型预测结果的可解释性。

### 4. 特征影响分析

应用可展示模型对不同材料参数和配合比变量的响应，帮助用户理解纤维类型、纤维含量、集料级配、沥青性质和体积参数对 MS/ITS 性能的影响。
